# 🌍 Happy Mappy - Tours & Travels

Happy Mappy is a full-stack travel planning web application that helps users explore destinations, view travel plans, create/save plans, and manage their travel bookings.

---

## 🚀 Technologies Used

### Frontend
- React.js
- Vite
- React Router DOM
- Lucide React
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs
- CORS
- dotenv
